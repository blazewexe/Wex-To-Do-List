# Wex To-Do List

This is a basic To-Do list made using HTML , CSS, JS and uses your browser's storage to store the tasks locally, so that it wont be lost after one refresh.

## Features

- Add, complete, and delete tasks
- Filter by all, active, or completed
- Sort by newest, oldest, or alphabetically
- Clear all completed tasks
- Responsive light-blue UI with keyboard and reduced-motion support

To preview locally, open `index.html` in a browser or run any simple static
server from the project folder:

```bash
python -m http.server
```
