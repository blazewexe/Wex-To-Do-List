# Wex To-Do List

[![Live Demo](https://img.shields.io/badge/Live-Demo-2ea44f?style=for-the-badge)](https://blazewexe.github.io/Wex-To-Do-List/)
[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge\&logo=github)](https://github.com/blazewexe/Wex-To-Do-List)
[![MIT License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)](https://github.com/blazewexe/Wex-To-Do-List/blob/main/LICENSE)

A simple and responsive To-Do List built using HTML, CSS and JavaScript.

Tasks are stored using the browser's `localStorage`, allowing them to persist even after refreshing the page.

## Live Preview

[View Wex To-Do List](https://blazewexe.github.io/Wex-To-Do-List/)

## Features

* Add, complete, and delete tasks
* Filter tasks by All, Active, or Completed
* Sort tasks by Newest, Oldest, or Alphabetically
* Clear all completed tasks
* Persistent storage using `localStorage`
* Responsive light-blue UI
* Keyboard support
* Reduced-motion support

## Running Locally

Clone the repository:

```bash
git clone https://github.com/blazewexe/Wex-To-Do-List.git
cd Wex-To-Do-List
```

Run a local server:

```bash
python -m http.server
```

Then open:

```text
http://localhost:8000
```

You can also open `index.html` directly in your browser.
